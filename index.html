FAQ

Questions about the Starfield Save Editor

Quick answers before you download and edit your first save.

Which Starfield save files does the editor support?
The editor works with Starfield .sfs character saves on Windows. It reads the character, skill, trait, credit, ship inventory, and item data stored in the save, and writes changes back to the same format after creating a backup.
Can I undo an edit if something goes wrong?
Yes. Before writing any changes, the editor automatically backs up the original character file. If an edit causes problems, you can restore the backup from inside the tool or copy it back into your saves folder manually.
Do I need to install mods or a mod manager?
No. starfield-save-editor is a standalone Windows application. It edits the save file directly, so you don't need a mod manager, script extender, or console commands to respec skills, set credits, unlock traits, or spawn items.
Is the Starfield Save Editor free?
Yes — it is free and open source. You can download the latest Windows build from the project page, and the source code is available on GitHub for review and contributions.
